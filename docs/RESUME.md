# Resume / portfolio description

**Nuvii Studio — AI-assisted press-on nail design platform**

- Built a browser-based ten-nail editor that turns custom press-on nail concepts into editable layers across realistic shapes, lengths, finishes, 2D artwork, 3D gel elements, charms, and chrome assets.
- Trained a custom SSD-1B LoRA on 140 domain-specific single-nail images and built a local Diffusers/FastAPI inference stack with Apple Silicon-safe decoding.
- Improved prompt adherence with a hybrid AI architecture: structured natural-language design plans, deterministic asset placement for known concepts, checkpoint/LoRA-strength diversification for novel art, and optional multimodal candidate quality control.
- Added reproducible model evaluation and dataset-balance tooling rather than relying on training loss or the final checkpoint alone.

**Stack:** Next.js, React, TypeScript, SVG/Canvas, Python, FastAPI, PyTorch, Diffusers, LoRA, OpenAI Responses API, Kaggle
