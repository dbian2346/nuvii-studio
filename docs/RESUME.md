# Resume and Portfolio Copy

## One-line project description

Browser-based press-on nail design platform with a ten-nail layer editor and a domain-specialized generative AI workflow.

## Resume bullets

- Built a responsive Next.js editor for designing complete ten-piece press-on nail sets with per-nail shape, colour, finish and layered asset controls.
- Created a controlled nail-art taxonomy and prepared a 200-image user-owned dataset with leakage-safe train, validation and test splits.
- Developed a low-memory LoRA training and inference pipeline that converts nail terminology into isolated, editable press-on nail artwork.

## Technical stack

Next.js, React, TypeScript, Canvas/SVG, Cloudflare Workers, Python, PyTorch, Diffusers, LoRA, Kaggle, Figma
